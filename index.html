會議記錄知識庫・未來擴充架構操作指南

本知識庫門戶專為「高頻持續擴充」設計，支援進金生能源服務 6692 的所有董事會、月會與週會無縫納入統一檢索體系：

1 建立結構化資料（Data Preparation）

在 data/ 資料夾下新增該會議的 JSON 檔案（例如 meeting_202611.json 與 slides_202611.json），結構完全對齊 8 大無雜訊簡報版型。

2 執行 /zero-noise-pptx 本地腳本產出簡報

執行 Python 指令：
python generate_noisefree_pptx.py --style hybrid --json data/slides_202611.json --output meeting_202611_zero_noise.pptx

3 在 catalog.json 註冊模組條目

在 catalog.json 的 modules 陣列加入新模組資料，前端入口將自動渲染卡片、產生投影片閱覽器並同步至即時搜尋索引！
