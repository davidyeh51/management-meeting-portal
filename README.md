## 🛠️ 如何擴充新會議記錄（3 步驟標準化流程）

1. **準備數據**：在 `data/` 資料夾中放入新增之會議分析 JSON（如 `data/meeting_YYYYMM.json` 與 `data/slides_YYYYMM.json`）。
2. **自動生成簡報**：執行 Python 腳本：
   ```bash
   python generate_noisefree_pptx.py --style hybrid --json data/slides_YYYYMM.json --output meeting_YYYYMM_zero_noise.pptx
   ```
3. **註冊模組**：在 `data/catalog.json` 中的 `modules` 陣列註冊該會議資訊。入口網站將自動掛載卡片並納入全站即時檢索體系！
